# 轻渡 Qingdu

Windows 局域网剪贴板与文件中转工具，帮助已配对的电脑传递文字、截图和文件。

## 下载与安装

前往 [最新版本下载页](https://github.com/dinosaur347/qingdu-releases/releases/latest)，下载名称以 `Setup-x64.exe` 结尾的安装包。

首次从旧版升级到 0.3.1，请先从系统托盘退出旧版，再手动安装。保留原有用户数据目录后，历史记录与设备授权会继续使用。

0.3.1 已绑定本仓库作为更新源。后续发布新版本后，可在软件内检查、下载，并选择重启安装更新。默认自动检查，下载与安装由使用者控制。

## 本仓库的内容

本仓库用于发布安装包、版本说明和自动更新辅助文件，不包含应用开发源码，也不接收剪贴板内容或设备配对数据。

- `.exe`：Windows x64 安装包。
- `.exe.blockmap` 与 `latest.yml`：软件自动更新所需的辅助文件。
- `SHA256SUMS.txt`：安装包的 SHA256 校验值。

设备之间的内容传输使用局域网；检查和下载软件更新需要访问 GitHub。
